02 / install

Two platforms, two files.

Android

solmish-release.apk
  1. Download the apk with the button above.
  2. Open the file. Android will ask you to allow installs from your browser, let it.
  3. Install, open, done. Future updates work the same way, just grab the new apk.

iOS

solmish-release.ipa
  1. Download the ipa with the button above.
  2. Sideload it with AltStore or Sideloadly, or sign it in Xcode with your Apple ID.
  3. Safari can't install ipa files directly, so a sideloading tool is required.
Both files come straight from the latest release, every time.
